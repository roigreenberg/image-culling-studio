What We Built

Designed specifically around how real wildlife & nature photographers shoot, cull, and edit in Lightroom Classic.

🦅

Project Kestrel + SigLIP 2

Combines MegaDetector, SAM-HQ silhouette segmentation, BioCLIP 2 species ID & false-positive gating, Kestrel sharpness, and SigLIP 2 eye-contact & action scoring across 100% of images.

🌅

Wildlife + Sunrise / Landscape

Routes animals to Track A and scenic sun/sunrise/sunset shots to Track B—plus a +15% Hybrid Light bonus when wildlife is caught in dramatic golden-hour light.

🎬

Smart Scenario & Flight Rules

No arbitrary count quotas. Splits scenarios automatically on ≥10% zoom changes, keeps complete good flying-bird sequences, and picks 1 standout frame per distinct pose for Edit.

🖥️

ImageCulling Studio Web UI

Fast local browser studio with side-by-side compare, 1:1 head crops, AI box & Canon AF point overlay, manual Burst Split, and full English/Hebrew keyboard shortcuts.

🛡️

Safe XMP Sync & Full Undo

Never touches RAW pixels or Lightroom Develop edits. Atomic XMP rating/label sync with pre-edit snapshots, Ctrl+Z undo, and full Hebrew/Unicode Windows path safety.

🧠

Learns Your Personal Taste

Every Keep, Edit, or Reject override you make can train a local LightGBM ranker over SigLIP 2 + BioCLIP 2 embeddings so future shoots rank closer to your own eye.

Easy Download & One-Click Setup

No Git and no Python pre-installed? No problem. Download the release ZIP and double-click the installer for your OS.

⬇ Download Latest Release 💻 Browse GitHub Repository 📖 Read Full README

🪟 Windows (NVIDIA CUDA or CPU)

  1. Download and unzip the latest ImageCulling-v*.zip release.
  2. Double-click Install_Windows.bat — automatically installs isolated Python 3.10, detects NVIDIA CUDA, installs packages, and downloads AI weights.
  3. Double-click Start_Windows.bat to launch the Web UI in your browser.

🍎 macOS (Apple Silicon MPS / Intel)

  1. Download and unzip the latest ImageCulling-v*.zip release.
  2. Double-click Install_MacOS.command — automatically installs isolated Python 3.10, Apple Silicon MPS PyTorch, ONNX Runtime, and AI weights.
  3. Double-click Start_MacOS.command to open ImageCulling Studio.

Built-in Auto-Updater & Changelog

ImageCulling Studio checks for updates automatically when opened and includes a one-click Check / Install Update button in Settings — preserving all your databases, models, and photos.
